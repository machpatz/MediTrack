# MediTrack Hospital Management System (HMS)

## Project Overview

MediTrack Hospital Management System (HMS) is a web-based application developed to improve the management of hospital operations by organizing patient information, medical records, appointments, pharmacy activities, billing, and other essential healthcare services in one centralized system.

The system is developed as an Information Technology project at The Nairobi National Polytechnic (TNNP).

## Objectives

- Improve the management of patient information and medical records.
- Simplify appointment scheduling and management.
- Support the management of doctors and healthcare staff.
- Organize pharmacy and laboratory activities.
- Generate reports to support hospital administration.
- Improve the efficiency and accuracy of hospital operations.

## Features

- **Patient Management:** Register and manage patient details.
- **Doctor Management:** Maintain doctor information.
- **Medical Records:** Store and manage patient medical records.
- **Appointment Management:** Schedule and manage appointments.
- **Pharmacy Management:** Organize pharmacy-related information.
- **Billing Management:** Manage patient billing information.
- **Laboratory Management:** Organize laboratory records and activities.
- **Reports:** Generate reports to support hospital administration.

## Technologies Used

- **Frontend:** HTML, CSS and JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Local Development Environment:** XAMPP
- **Code Editor:** Visual Studio Code

## System Requirements

- Windows, Linux or macOS computer
- XAMPP or another compatible PHP/MySQL environment
- A modern web browser
- A code editor such as Visual Studio Code

## Installation and Setup

1. Install and open XAMPP.
2. Copy or clone this project into the XAMPP `htdocs` directory.
3. Start the Apache and MySQL services.
4. Open phpMyAdmin in your browser.
5. Create the required MySQL database and import the project's database SQL file, if provided.
6. Update the database connection settings in the project configuration file.
7. Open the application in your browser using the appropriate localhost URL.

Example:

`http://localhost/MediTrack-HMS/`

*Note: Update the folder name, database name and URL to match your actual project setup.*

## Project Structure

## Security Considerations

- Do not commit database passwords, API keys or other private credentials to GitHub.
- Validate and sanitize user input.
- Use secure password hashing for user accounts.
- Apply role-based access control to restricted functions.
- Protect patient information and medical records from unauthorized access.
